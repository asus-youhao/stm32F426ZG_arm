🧭 職涯技能地圖

把「學習樹」對應到真實世界的機器人 / 馬達控制韌體工程師（robotics / motion-control firmware engineer）職缺：需要哪些技能、初/中/高階各要會什麼、國內外實際要求對照。整理自公開招募與技術資源（來源見頁尾），投遞前以當下 JD 為準。
C/C++STM32/Cortex-MCANopen CiA 301/402 EtherCAT CoE/DCRTOS / PREEMPT_RT伺服/運動控制

🌳深度技能樹（6 大主幹）

一位能獨當一面的運動控制韌體工程師，能力大致分成六條主幹。愈往右愈進階，右側圖例對應本手冊 L1→L3 與最終專案。

🪜初階 → 中階 → 高階

年資只是參考，真正差別在「能負責的範圍」：從「照著做一個模組」到「一個人扛整條運動控制產品線」。

1

初階 Junior

0–2 年
🎯 能在資深帶領下完成單一功能模組，會用工具把問題找出來。
  • C 語言紮實：指標、struct、volatile、中斷安全的基本觀念
  • STM32 HAL：GPIO/UART/Timer 設起來、燒得進去、printf 除得了錯
  • 看得懂 datasheet 的暫存器表與時序圖；會用邏輯分析儀/candump
  • 知道 CAN 訊框長相，能照協定文件收發封包
  • Git 基本流、看得懂別人的韌體架構（如本 repo 的分層）
對應 L1 全部L2-7~9
2

中階 Mid-level

3–6 年
🎯 能獨立設計並實作一個子系統：一條 fieldbus、一組多軸、一套安全機制。
  • CANopen 全套：NMT/heartbeat、SDO/PDO、自己寫得出輕量主站
  • CiA 402 使能交握與 Fault 處理寫成可測試的程式碼
  • 算得出頻寬預算並據此定架構（500Hz vs 1kHz 那種決策）
  • 多軸同步控制：CSP 插補、軌跡限速、following error 除錯
  • 安全設計：通訊看門狗、急停鏈路、使能門檻（含「餵狗條件」這種細節）
  • 可測試架構：HAL 切層、PC 模擬、單元測試進 CI
對應 L2 全部L3-13~16專案 A 完整
3

高階 / 資深 Senior

7 年以上
🎯 能從 0 到 1 扛整條產品：架構選型、bring-up、量產、跨團隊，並為選型結論負責。
  • EtherCAT 深水區：ESM 除錯（AL status）、DC 調校、ESI/PDO 客製、SOEM/IgH 改造
  • 即時系統調校：PREEMPT_RT、CPU 隔離、抖動量測方法論，數據說話
  • 系統選型能力：CANopen vs EtherCAT vs CAN FD，含廠商生態/控制權風險評估（本 repo 專案 B 的教訓）
  • 7-DoF 冗餘 IK、力控/阻抗控制、雙臂協同這一級的控制理論落地
  • 功能安全與認證思維：STO 鏈路、失效模式分析、機械指令/CE
  • 帶人、code review、跨部門（機構/電控/軟體/演算法）協作與技術決策文件
對應 L3 全部專案 A+B 兩條都完整

🌍國內外實際職缺對照

以下整理自 2025–2026 公開招募平台與元件商技術文件中，機器人 / 伺服 / 運動控制韌體職缺的常見要求（來源見頁尾）。

🌏 國際

層級 / 類型常見必備技能加分 / 資深要求
🌐 Embedded/Firmware Engineer（Junior/Mid） C/C++、Cortex-M（STM32/Nordic/TI 其一）、UART/SPI/I2C/CAN、RTOS（FreeRTOS/Zephyr）、示波器/邏輯分析儀除錯、Git CANopen/EtherCAT 經驗、Python 測試自動化、CI/CD
🦾 Motion Control / Servo Drive Engineer（Mid/Senior） CiA 402 profile（狀態機、CSP/CSV/CST、PDO 映射）、伺服調機、編碼器介面、EtherCAT CoE 或 CANopen 整合 DC 同步多軸系統、FOC/電流環、功能安全（STO/SS1）、IEC 61800
🤖 Robotics Software/Firmware（Senior） Linux 即時系統（PREEMPT_RT/Xenomai）、EtherCAT 主站（IgH/SOEM/acontis）、運動學/軌跡規劃、ros2_control 類框架 整機從 0 到 1、跨團隊架構決策、量產與安全認證經驗

🇹🇼 台灣（104 / CakeResume 常見）

層級常見必備技能加分 / 資深要求
初階 韌體工程師 C 語言、STM32/Cortex-M 開發經驗、UART/SPI/I2C、看得懂電路圖與 datasheet、示波器基本量測 CAN bus、RTOS 概念、馬達控制課程/專題
中階 機器人/運動控制韌體（機械手臂、AMR、自動化設備廠） CAN/CANopen 或 EtherCAT 實務、伺服馬達整合（含調機）、多軸控制、RTOS、與電控/機構協作 CiA 402、EtherCAT 主站經驗、Linux、安全迴路設計
資深 / 技術主管 整機系統架構、fieldbus 選型與頻寬設計、即時 Linux、帶隊 code review、量產導入 功能安全/認證、力控與協作機器人經驗、跨國供應商整合（如本 repo 對 EYOU 的整合經驗）
怎麼用這張表：照本手冊 L1→L3 打底（命中「初階」欄），做完專案 A（雙臂 CANopen 主站）就有中階職缺要的完整證據鏈：fieldbus 主站 + CiA402 + 多軸 + 安全 + 可測試架構。再補專案 B（EtherCAT + RT Linux）與它的除錯實戰紀錄，就是往資深走的敲門磚。資深職缺剩下的（量產、認證、帶人）要靠實戰累積，無法只靠自學速成。
