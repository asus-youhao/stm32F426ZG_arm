🤖 STM32 學習手冊

一條龍路線：從點亮一顆 LED，到用 CANopen / EtherCAT 驅動 14 軸 EYOU PHU 雙臂機器人。所有範例直接取自本 repo 的真實程式碼。
🟢 L1 初階 🔵 L2 中階 🟣 L3 高階 🎯 兩條專案路線

🌳學習樹總覽

三層階梯往上長，最後分岔成兩個實戰專案（都是本 repo 真實做過的路線）。點卡片或左側里程碑進入各層教學。

怎麼用：每一層都是前一層的地基。建議照 L1→L2→L3 順序做完最小練習，再挑一條專案路線收尾。 兩條專案共用 L1/L2 的 MCU 與匯流排基本功，差別在 L3 的重點：A 走 MCU 上的 CANopen 主站（本 repo firmware/），B 走 PC 上的即時 EtherCAT 主站（本 repo feature/linux-*-ethercat-master 系列分支）。

📦教材 = 這個 repo 本身

這不是抄書的教學，每一節都對到 repo 裡實際存在、實際跑過的程式碼與設計文件。

硬體平台與雙臂關節配置（PHU14/17/20 ×14 軸）CLAUDE.md 關節對應表、doc_EYOU/ 原廠 datasheet🟢 L1
