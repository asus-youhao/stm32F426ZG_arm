# DC 鎖相 PI + 漂移模擬（項目 8；WP-L2.2 的 SIL 預演）

- 日期：2026-07-05
- 分支：`feature/ecat-backend-sim`
- 類型：feat + test

## 變更摘要

1. **`firmware/ecat/ec_dc_pll.[ch]`**：DC 鎖相 PI 控制器——SOEM 路徑主站是
   DC「跟隨者」，每週期 `err = ec_master_dc_error_us()` → PI →
   `eng_phase_trim_us()` 把喚醒點鎖到從站柵格。**整數化殘差進位**
   （error-feedback）：200 ppm @1 kHz 的漂移只有 0.2 µs/tick，整數 trim
   直接四捨五入會鎖不住；帶進位後平均輸出可解析次 µs 級。含飽和抗積分。
2. **門面**：`ec_master.h` 增 `ec_master_dc_error_us()`（SOEM 由 ec_DCtime
   導出；IgH 主站發號恆 0）。
3. **sim 漂移模型**：`phu_ecat_set_dc_drift(dt_us, ppm)`——從站柵格週期
   = dt×(1+ppm/1e6)，exchange 時回報主站喚醒 vs 柵格的相位差。
4. **掛載**：`bus_ecat.c` 增 `bus_ecat_dc_pll_enable/disable(engine)`，
   於 pump（exchange 後）施加 trim。

## 動機 / 背景

WP-L2.2（DC 鎖相，σ<10 µs）是方案 A 的拍板點。控制器的極性、增益與
收斂性不需要等真機——SIL 先把 PI 調到收斂，真機只驗「真實時鐘/抖動下
的 σ」，把拍板點的未知數縮到最小。這也是交叉盤點缺口 1
（eng_phase_trim_us）的閉環驗證。

## 驗證方式

`firmware/tests` 4925 檢查 0 失敗，test_dc_pll 覆蓋：

- PI 單元：極性（晚到→提前喚醒）、限幅、殘差進位（固定 2 µs 誤差
  50 步累計輸出非零）。
- E2E（完整 app 棧 @1 kHz）：無鎖相基線 +200 ppm → 2000 tick 誤差發散
  >100 µs；開鎖相 → 收斂後 2000 tick 內 **|err| ≤ 3 µs**；−500 ppm
  反向亦收斂。
- pc_master 建置零警告。
