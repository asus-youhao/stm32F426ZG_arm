# WP-L0.4：RT 調校一鍵腳本 rt_setup.sh

- 日期：2026-07-05
- 分支：`feature/linux-rt-ethercat-master`
- 類型：feat（腳本，無韌體變更）

## 變更摘要

新增 `firmware/rt/rt_setup.sh`：把 `linux-rt-ethercat-master-plan.md` §3.2
的 RT 調校基線腳本化（方案 A/B/C 的 RT 機共用）：

- **grub 內核參數**（`--grub`，寫 `/etc/default/grub.d/90-rt.cfg`）：
  `isolcpus/nohz_full/rcu_nocbs`（隔離核）、`irqaffinity`（家務核）、
  `skew_tick=1`、`intel_pstate=disable`、`max_cstate`、`nosoftlockup`。
- **執行期調校**（`--apply`）：governor=performance、關 Turbo、
  其餘 IRQ → 家務核、指定 NIC/CAN 介面 IRQ → 隔離 IRQ 核、
  對應 irq thread `chrt -f 85`（規劃 §3.2 優先權表：搶在 cyclic 80 前收包）。
- **cpu_dma_latency**（`--hold-dma`）：常駐持有 `/dev/cpu_dma_latency=0`
  （需常駐 holder 才有效，建議 systemd 化）。
- **驗收檢查**（`--check`）：PREEMPT_RT 內核、isolcpus 生效、governor，
  並印出 cyclictest/hwlatdetect 門檻命令（max<50 µs / SMI≈0）。
- 冪等、預設 dry-run（只印不做）；`--cores A,B --nic IF --can IF` 參數化
  （`--can` 供方案 C 的 PCAN 卡同用）。

## 動機 / 背景

WP-L0.4 DoD「腳本冪等、重跑安全」。此腳本是 A/B/C 三方案 RT 機的共同
前置（H3 抖動驗收也用它），純軟體可先行，真機拿到後直接套用。

## 影響範圍

- 新增：`firmware/rt/rt_setup.sh`。不影響任何韌體/程式行為。

## 驗證方式

- `bash -n` 通過；本機（非 RT）dry-run 與 `--check` 實測：正確列出全部
  調校命令、正確回報 ✗（非 PREEMPT_RT / isolcpus 未生效 / powersave）。
- **待 RT 真機驗**：`--grub` 重開機後 isolcpus 生效、`--apply` 後
  cyclictest 12h max < 50 µs（WP-L0.5 / WP-H3 驗收）。
