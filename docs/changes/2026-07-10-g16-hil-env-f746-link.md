## 驗證結果（板端 VCP 115200 實錄）

```
掃鏈：2 從站（vendor=0x00001097 product=0x00010002 ×2,EYOU 身分）
PDO 映射：12O+12I bytes → AL：SAFEOP=OK → CoE 0x1000=0x00020192 → AL：OP=OK
DC：無(假從站,PLL 待真 ESC)
cw=0x06→sw=0x0021、0x07→0x0023、0x0F→0x0027（CiA402 使能三步）
SE4 tick@1kHz×10s：late p50=0µs p99=0µs max=19µs overrun=0 交換max=1018µs → PASS
  （WKC ok=9049/10000）
Phase B 100Hz×10s：WKC ok=1000/1000 CSP pos=5000（目標 5000）→ PASS
```

- **SE4 Phase A PASS**：TIM6 1 kHz 週期源品質達標（p99=0µs、零 overrun）。
- **Linux AF_PACKET 明顯優於 npcap**：1 kHz 下 WKC ok 90.5%（npcap 時代 miss
  幾乎全滅）；100 Hz 下 1000/1000 零漏。
- 鏈路維持 **10BASE-T 全雙工**（SSR=0x1054;板端 `ECAT_PHY_FORCE_10M` 組態）。
  100M 穩定性問題（線材/供電）依 2026-07-08 文件仍為 HIL-2 前置待辦。

## 重跑指令（G16）

```bash
# 板端建置（HAL 包在 ~/toolchains/STM32Cube_FW_F7）
cd firmware && make ecat-probe CUBE_FW_F7=$HOME/toolchains/STM32Cube_FW_F7 \
  C_DEFS="-DUSE_HAL_DRIVER -DSTM32F746xx -DECAT_PHY_FORCE_10M \
          -DEC_TIMEOUTRET=50000 -DEC_TIMEOUTSAFE=200000"
arm-none-eabi-objcopy -O binary build-ecat/ecat_probe_f746.elf build-ecat/ecat_probe_f746.bin
st-flash --reset write build-ecat/ecat_probe_f746.bin 0x08000000
# PC 假從站（需 root 或 setcap;停止用 sudo pkill -f ecat_slave.py）
sudo python3 firmware/sim_py/ecat_slave.py --iface enx00e04c6809b6 --axes 2 --wd-ms 0
# 觀察:/dev/ttyACM0 115200
```
