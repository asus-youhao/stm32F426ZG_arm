# 2026-07-07 SE3：F746 SOEM bare-metal port + HIL-0 探測韌體（可編可燒）

## 變更摘要

WP-SE2 完成 + WP-SE3 程式完成（板端驗證待硬體接線）：

1. **SOEM v2 bare-metal port**（`firmware/ecat/f7/`）：
   - `soem/ec_options.h`：取代 cmake 生成版；尺寸對 F746 縮編（MAXSLAVE 18、MAXBUF 8、MAXODLIST 64）
   - `osal_defs.h` / `osal.c`：DWT cycle counter 計時（µs 級逾時、32→64-bit 軟體延伸）、
     busy-wait usleep、互斥鎖 no-op（單執行緒 loop engine）、執行緒不支援
   - `nicdrv.h` / `nicdrv.c`：索引化收發緩衝管理照抄 oshw/rtk 版，傳輸層抽換為
     `oshw_mac_init/send/recv` 三函式；單網孔、無冗餘
   - `oshw.c`：**F746 ETH MAC(RMII) + LAN8742A PHY 低階驅動**——
     MPU region 7 把 SRAM2(0x2004C000,16KB) 設 non-cacheable，DMA 描述符/收發緩衝
     全放該區（**收發路徑零 cache 維護**）；PHY reset→自動協商→速率/雙工回寫 MAC；
     混雜模式；HAL 新版 ETH API（RxAllocate/RxLink callback + polling ReadData）
2. **HIL-0/HIL-1 探測韌體**（`board/ecat_probe_main.c`，target `make ecat-probe`）：
   VCP 輸出 link 狀態→掃鏈→身分→PDO 映射→SAFEOP→OP→CiA402 使能→1kHz CSP 點動 2 秒 + WKC 統計；
   無從站時每秒重掃（HIL-0 用 Wireshark 看 0x88A4 幀）
3. **linker script**（⚠ 影響記憶體佈局）：RAM 320K→304K，SRAM2 16K 割為 `ETHRAM` 區
   （`.EthNoCache` NOLOAD section）；`_estack` 0x20050000→0x2004C000（避開 ETH 緩衝）
4. `firmware/Makefile`：新增 `ecat-probe` / `flash-ecat` target（獨立 build-ecat/，不動 bring-up 主韌體）

## 硬體行為標註（CLAUDE.md 要求）

- **腳位**：啟用 ETH RMII——PA1/PA2/PA7、PB13、PC1/PC4/PC5、PG11/PG13（AF11）+ USART3 PD8/PD9（VCP）
- **周邊**：ETH MAC + DMA、SYSCFG PMC（MII_RMII_SEL）、MPU region 7、DWT CYCCNT
- **時脈**：216 MHz（HSE bypass 8MHz × PLL），同 bring-up 主韌體
- 只影響 `ecat-probe` target；bring-up 主韌體僅受 linker 佈局變更影響（RAM 少 16K + 堆疊頂下移，
  bss 13.9K 遠低於 304K，無風險）

## 驗證方式

- `make ecat-probe`：arm-none-eabi-gcc 13.3 編譯連結全過（= SE2 的 arm build 驗收）；
  map 檢視 `.EthNoCache` @0x2004C000、`_estack` @0x2004C000 正確
- `make` 回歸：bring-up 主韌體照常編譯
- **待硬體**（下一步 HIL-0）：`make flash-ecat` 燒錄 → 網線接 PC NIC →
  Wireshark 過濾 `ecat` 看掃鏈幀；PC 跑 `ecat_slave.py --iface <NIC>` 即 HIL-1 全流程
- 已知限制：`ecx_config_init` 的 PHY link 等待最長 5 秒；DC 鎖相（ec_dc_pll 接真 ec_DCtime）
  與 TIM 1kHz 週期源留 SE4（本韌體用 HAL_Delay 節拍，非即時級）
