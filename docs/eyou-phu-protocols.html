EYOU PHU 馬達 — 支援協定與控制模式

人形雙臂（每臂 7-DoF，共 14 軸） · 依原廠手冊 v1.06 / 規格書 v1.14 整理

1 · 支援的通訊協定

同一套 CiA 402 物件字典可在兩種傳輸層運作；硬體連接埠同時具備 CAN FD 與 EtherCAT。

協定傳輸層速率同步適用
CANopen CAN（本關節為 Classic CAN 2.0B） 預設 1 Mbps，可選 500k/250k/125k/100k/50k/20k 軟體 SYNC（抖動較大） 單關節 bring-up、低頻測試
EtherCAT (CoE) 工業乙太網 100 Mbps（菊鏈） 高吞吐，單週期可更新 14 軸 硬體 DC 分散式時鐘（抖動極低） 高頻多軸同步、力控、1 kHz+

※ 實體接口為 CAN FD（In/Out） + EtherCAT（In/Out） + STO + 電源；但 CANopen 協定依手冊以傳統 CAN 速率（≤1 Mbps）運作。CoE = CANopen over EtherCAT（手冊 §1.2 明載）。

3 · 人形雙臂該用哪一種 Mode？

✅ 建議：以 EtherCAT(CoE)+DC 同步，跑循環同步模式

位置型任務 → CSP (8)

  • 主站（1 kHz）做 joint-space / task-space 軌跡規劃，每週期下目標位置
  • 剛性高、軌跡跟隨精準
  • 適合：抓取、定位、雙手協同搬運的位置同步

順應/力控任務 → CST (10) / CSF (13)

  • 主站送目標轉矩，實現 笛卡爾阻抗 / 順應控制
  • 人機互動安全、接觸柔順、可吸收外力
  • 適合：插拔、貼合、雙手夾持同物件的內力控制

實務建議組合（人形雙臂）

情境建議模式傳輸層
初期單關節 bring-up / 校正PP / HMCANopen
單臂 / 雙臂 1 kHz 位置控制（剛性）CSPEtherCAT
task-space 阻抗 / 順應 / 安全互動CST 或 CSFEtherCAT
雙手夾持同物件（內力/協同）CST/CSF + 位置疊加EtherCAT

📌 一句話結論

人形雙臂高頻控制 → 走 EtherCAT(CoE)+DC，主用 CSP（位置）並依任務切到 CST / CSF（轉矩/力控阻抗）。 CANopen（Classic CAN ≤1 Mbps）保留給單軸 bring-up 與低頻測試。
