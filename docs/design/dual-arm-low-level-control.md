# Dual-Arm Low-Level Control — 需求 / 架構概述

- 目標 MCU：**STM32F746ZG**（ARM Cortex-M7，216 MHz，1 MB Flash，320 KB SRAM，含 FPU + L1 Cache）
- 文件層級：需求 / 架構概述（不含底層暫存器級細節）
- 狀態：草案（draft）

> ⚠️ 注意：本 repo 名稱為 `stm32F426ZG_arm`，但本實作目標 MCU 為 **STM32F746ZG**（Cortex-M7），兩者為不同晶片，請勿混用腳位、時脈與周邊設定。

## 1. 實作目標

在單顆 STM32F746ZG 上實現**雙臂（dual-arm）機器手臂的低階即時控制（low-level control）**，負責：

- 各關節（joint）的伺服控制：位置 / 速度 / 力矩（torque/current）控制迴路。
- 雙臂同步：兩臂之間在時間上對齊，確保協同動作的一致性。
- 與上位機（high-level planner / PC / SBC）交握：接收軌跡命令、回報狀態。
- 安全機制：超限保護、急停、看門狗。

本層**不負責**運動規劃、軌跡生成、逆運動學等高階運算（由上位機處理）；MCU 專注於高頻、確定性的閉迴路控制。

## 2. 系統架構（概念）

```
┌──────────────────────────┐
│   上位機 (High-Level)     │  軌跡 / 目標命令、狀態監看
│   PC / SBC / ROS          │
└────────────┬─────────────┘
             │  通訊匯流排 (CAN-FD / Ethernet / UART)
┌────────────▼─────────────┐
│   STM32F746ZG (本專案)    │
│   Low-Level Control       │
│  ┌────────────────────┐  │
│  │ 命令解析 / 狀態回報 │  │
│  ├────────────────────┤  │
│  │ 控制排程器 (RTOS)   │  │  固定頻率控制迴路
│  ├──────────┬─────────┤  │
│  │ 左臂控制 │ 右臂控制 │  │  每臂 N 個關節
│  ├──────────┴─────────┤  │
│  │ 安全 / 看門狗 / 急停 │  │
│  └────────────────────┘  │
└──┬──────────────────┬────┘
   │ 驅動 / 感測介面    │
┌──▼───┐  ┌────────┐  ┌▼──────┐
│ 馬達 │  │ 編碼器 │  │ 力矩/ │
│ 驅動 │  │/位置感測│  │ 電流  │
└──────┘  └────────┘  └───────┘
```

## 3. 功能模組（規劃）

| 模組            | 職責                                                         |
| --------------- | ------------------------------------------------------------ |
| 通訊介面        | 與上位機交握；接收命令、回報關節狀態                         |
| 命令解析        | 解碼軌跡 / 目標點 / 模式切換                                 |
| 控制排程器      | 以固定頻率觸發控制迴路（建議用 RTOS 或硬體 timer + ISR）     |
| 關節控制迴路    | 串級控制：位置 → 速度 → 電流/力矩；每關節獨立增益            |
| 雙臂同步        | 兩臂控制迴路共用時基，確保同步更新                           |
| 感測器介面      | 讀取編碼器（位置/速度）、電流/力矩回授                       |
| 馬達驅動介面    | 輸出 PWM / 命令至馬達驅動器                                  |
| 安全 / 急停     | 限位、過流、過溫、通訊逾時 → 進入安全狀態；獨立看門狗        |
| 狀態管理        | 系統狀態機：Init → Idle → Enabled → Running → Fault          |

## 4. 即時性需求（待定，後續細化）

- 控制迴路頻率：建議 1 kHz 起（依關節數與運算負載調整），需於後續文件量化。
- 確定性：控制迴路抖動（jitter）需受限，避免被通訊或非即時任務干擾。
- 雙臂一致性：兩臂控制更新需在同一控制週期內完成。

## 5. 待決議項（Open Questions）

6. 控制策略：是否需要力矩控制 / 阻抗控制，或僅位置控制？
