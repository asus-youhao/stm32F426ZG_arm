# Dual-Arm Control 工作規劃（Work Plan）

- 目標：雙臂（各 7-DoF,共 14 軸）低階控制,含 **joint-space** 與 **task-space** 高頻控制器（**1 kHz**）,並整合雙臂協同。
- 致動器：EYOU PHU（CANopen / EtherCAT-CoE,CiA 402:PP/PV/PT/CSP/CSV/CST/CSF）
- 文件層級：工作規劃 / 架構
- 狀態：草案(draft)

## 1. 控制系統分層

```
┌──────────────────────────────────────────────┐
│ L4 雙臂協同 (Bimanual / Coordination)          │  共用時基、相對約束、自碰撞檢查
├──────────────────────────────────────────────┤
│ L3 Task-space 控制 (Cartesian, 1 kHz)          │  IK/Jacobian、Cartesian PD/阻抗、力控
├──────────────────────────────────────────────┤
│ L2 Joint-space 控制 (1 kHz)                     │  軌跡插值、關節 PD/PID + 前饋
├──────────────────────────────────────────────┤
│ L1 關節驅動抽象 (CiA 402)                       │  狀態機、模式切換(CSP/CST/CSF)、單位換算
├──────────────────────────────────────────────┤
│ L0 通訊層 (CANopen / EtherCAT-CoE)             │  PDO/SDO、DC 同步、即時排程
└──────────────────────────────────────────────┘
```

> 1 kHz 即時性:控制週期 1 ms,需確定性排程(DC 同步或硬體 timer + ISR),抖動受限。

## 3. 建議里程碑（順序）

1. **M1**：WP0 拍板 + WP1 單節點通訊 + WP2 單軸轉動。
2. **M2**：WP3 單臂 joint-space 1 kHz 點到點。
3. **M3**：WP4 單臂 task-space 1 kHz（FK/IK/Jacobian + Cartesian PD）。
4. **M4**：WP5 雙臂整合 + WP6 安全。
5. **M5**：WP7 上位機整合與整機測試。

## 4. 關鍵風險 / 待決議

1. **1 kHz × 14 軸的通訊頻寬** → 偏向 EtherCAT-CoE（DC 同步）;CANopen Classic 1 Mbps 對 7 軸/路高頻吃緊。
2. **主站架構**:STM32 當 EtherCAT 主站不典型;1 kHz task-space + 動力學運算可能需 PC/SBC 當主站,STM32 任即時 I/O / 從站。→ 須於 WP0.2 拍板。
3. **IK 即時性**:7-DoF 冗餘臂 IK 在 1 kHz 下需高效解法（解析 + 數值修正 / DLS）。
4. **力控頻寬**:規格書力控閉環頻寬與阻抗控制頻率有限,task-space 力控需依其上限設計。
5. **動力學模型**:重力/摩擦前饋需 WP0.4 的慣量參數。
