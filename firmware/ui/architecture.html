雙臂人形 3D 模擬器 — 整體架構

STM32F746 CANopen 主站 · 14 軸 EYOU PHU 假硬體 · three.js TF 視覺化　（本頁為離線靜態文件）

1. 系統總覽

純 Python 假硬體後端跑 14 顆 PHU 馬達（完整 CiA402 物件字典 + 500 Hz 控制）， 透過 WebSocket（遙測/命令）與靜態 HTTP（模型/設定/前端）對外； 瀏覽器端 viewer3d.html 以 three.js 依 URDF TF 樹建人形骨架， 即時把每軸角度畫成 3D 動作，並提供控制與設定介面。

馬達零點紅線（轉子） 零點參考（定子） 低扭矩→高扭矩 目標殘影

3. 座標系與「手臂垂下＝零點」

慣例

  • Z 向上、X 向前、Y 向左（右手系，重力 −Z）
  • 單位：m / rad（前端可切 deg）；counts↔rad 用 CPR=524288/2π
  • base_link 軀幹原點；左肩 (0,+0.20,0.50)、右肩 (0,−0.20,0.50)
  • q=0 → 雙臂沿 −Z 自然垂下（人站立、手臂貼身）
  • 零點紅線：轉子紅線對齊定子刻痕＝機械零；home_offset(0x607C) 旋轉定子刻痕

3-1-3 擬人臂 TF 鏈（每臂 7 軸）

base_link
 └─ J1 肩 pitch  (axis Y)
     └─ J2 肩 roll (axis X)
         └─ J3 肩 yaw (axis Z) ── upperarm 0.30
             └─ J4 肘 (axis Y) ── forearm 0.28
                 └─ J5 腕 roll (axis Z)
                     └─ J6 腕 (axis Y)
                         └─ J7 腕 (axis X) ── hand 0.08

q=0 時肩(0,±.20,.50)→肘(0,±.20,.20)→手(0,±.20,−.08)

5. 模組職責

sim_py/model/dual_arm.urdf唯一真相：link/joint/origin/axis/limit + 視覺（手臂垂下＝零）
sim_py/model/robot_config.json可調疊加：bus/node/model、home_offset、soft limit、Kp/Kd、mesh 檔名、顯示、preset

sim_py/ws_server.pySim（14 馬達+控制）、WebSocket、靜態 HTTP、set_config/preset、遙測
ui/viewer3d.htmlthree.js TF 場景、紅色零點紅線、遙測驅動、殘影/上色、控制+設定 UI、mesh 載入
ui/vendor/*vendored three.js（three.module / OrbitControls / STLLoader / GLTFLoader）離線用

6. WebSocket 協定

命令（前端→後端）

{cmd:"enable"} / {cmd:"estop"}
{cmd:"mode", value:8}
{cmd:"jog",  joint:i, value:rad}
{cmd:"move", joint:i, delta:rad}
{cmd:"read", node,bus,index[,sub]}
{cmd:"write",node,bus,index,value}
{cmd:"preset", name:"home_arms_down"}
{cmd:"set_config", path:"control.Kp", value:150}
{cmd:"set_config", config:{...整包...}}

遙測（後端→前端，20Hz）

{
  motors:[{ name, model, bus, node,
    cw, sw, state, target, actual,
    torque, current, peak, ratedC,
    q, qTarget, home }, …14],
  frames:[…], cobids:[…],
  tx:[..], rx:[..], estop,
  model_rev            // 變動→前端重載模型
}

8. 如何執行

# 1) 啟動後端（WebSocket :8765 + 靜態 HTTP :8090，埠被占用會自動避讓）
cd firmware/sim_py
python3 ws_server.py            # 或 python3 ws_server.py 8765 <http-port>

# 2) 瀏覽器開（務必用 http://，不要 file://）
http://localhost:8090/ui/viewer3d.html

# 3) 放 CAD 網格（可選）
firmware/sim_py/model/meshes/  +  robot_config.json 的 "meshes"

終端機會印出實際使用的 HTTP 埠。three.js 為 vendored，無需連網。
